## 🔭 Projects

**🤖 [Tiny Agent](https://github.com/kyle-hopping/research-agent)** — *Python · Groq · Chroma · asyncio · RAG · pytest*  
Tool-using AI agent built from scratch with no agent framework, featuring web search, a sandboxed calculator, and long-term semantic memory with automatic recall. Includes a multi-agent research team where a planner, concurrent async researchers, a writer, and a critic produce fact-checked, cited reports.

**🦜 [LangChain Playground](https://github.com/kyle-hopping/langchain-playground)** — *Python · LangChain · Groq · Embeddings · RAG*  
A progressive series of LangChain v1 lessons covering messages, streaming, chains, structured output, tool-calling agents, and conversation memory, ending with retrieval-augmented generation built both as a chain and as an agent.

**🛠️ [Agent Playground](https://github.com/kyle-hopping/agent-playground)** — *Python · OpenAI API · Tool Calling · CLI*  
Step-by-step build of an AI coding agent, from a single API call to an interactive terminal assistant that can list, read, and write files and run shell commands behind a confirmation prompt.

**📈 [Stock Analytics](https://github.com/kyle-hopping/stock-analytics)** — *C++ · Kafka · InfluxDB · Docker*  
Real-time stock analytics dashboard that ingests live market data via Kafka, processes it in parallel using a C++ thread pool, stores results in InfluxDB, and streams to a browser dashboard over WebSockets.

**🔢 [MPI Algorithm Suite](https://github.com/kyle-hopping/parallel-mpi)** — *C · MPI · HPC*  
A suite of high‑performance MPI programs tackling classic parallel‑computing problems: dense & sparse PageRank, co‑rank parallel merging, and a distributed segmented sieve for trillion‑scale prime‑gap analysis.
Designed for scalability, low‑overhead communication, and clean parallel decomposition.

**🍽️ [Find Dine](https://github.com/kyle-hopping/Find-Dine)** — *HawkHacks 2022 · Winner: Best Use of Google Cloud*  
A personalized itinerary generator for local attractions using the Google Maps & Places API. Built with a team of 4 in 36 hours among 650+ participants.

**💰 [Money Manager](https://github.com/kyle-hopping/money-manager)** — *Python · Tkinter · Matplotlib*  
Desktop budgeting app with an expense tracker, savings allocator, financial goals, and a live-updating donut chart dashboard. Features real-time validation, persistent JSON storage, and a clean modular architecture.
