## 🔭 Projects

**📈 [Stock Analytics](https://github.com/kyle-hopping/stock-analytics)** — *C++ · Kafka · InfluxDB · Docker*  
Real-time stock analytics dashboard that ingests live market data via Kafka, processes it in parallel using a C++ thread pool, stores results in InfluxDB, and streams to a browser dashboard over WebSockets.

**💰 [Money Manager](https://github.com/kyle-hopping/money-manager)** — *Python · Tkinter · Matplotlib*  
Desktop budgeting app with an expense tracker, savings allocator, financial goals, and a live-updating donut chart dashboard. Features real-time validation, persistent JSON storage, and a clean modular architecture.

**🍽️ [Find Dine](https://github.com/kyle-hopping/Find-Dine)** — *HawkHacks 2022 · Winner: Best Use of Google Cloud*  
A personalized itinerary generator for local attractions using the Google Maps & Places API. Built with a team of 4 in 36 hours among 650+ participants.

**🔢 [Parallel Prime Gap Analyzer](https://github.com/kyle-hopping/parallel-mpi)** — *C · MPI · HPC*  
Distributed app analyzing prime gaps over ranges up to 10¹² on SciNet's HPC cluster. Achieved ~3.7× speedup scaling from 2 → 8 processes using a parallelized segmented Sieve of Eratosthenes.
